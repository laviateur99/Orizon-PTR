# Installation — Orizon Flight Director 19.27.1

La copie active dans `Documents/Orizon-PTR` est déjà mise à jour.

Pour installer l'archive sur une autre copie :

1. Fermer Flight Director.
2. Conserver une sauvegarde de l'ancien dossier `Orizon-PTR`.
3. Extraire l'archive et placer son contenu dans `Documents/Orizon-PTR`.
4. Double-cliquer sur `start-flight-director.command`.

Au premier démarrage, les dépendances sont installées automatiquement si elles ne sont
pas présentes. Cette version n'exécute aucune migration Firestore et ne modifie aucun
dossier étudiant existant pendant l'installation.
