# Orizon Flight Director v14.0.0

## Installation

```bash
cd ~/Documents/Orizon-PTR
npm install
npm run dev
```

## PTR électronique

La version 14 ajoute :
- plans de leçon;
- exercices;
- évaluation TC à quatre points;
- calcul automatique de la note la plus faible;
- commentaires;
- signatures;
- historique;
- progression.
